Assignment Section B & C Built-in Compliance Architecture

01. ERROR HANDLING IN N8N

Catch-nodes intercept AI timeouts or Bubble API 500s. The workflow does not fail silently: it posts an error record with the exact code to Bubble's notification log and updates status to Failed.

✓ No silent drops
02. NON-BLOCKING BUBBLE UI

The frontend never hangs on an indefinite spinner. Webhook triggers respond with an asynchronous Task ID within 250ms, then poll or listen on the WebSocket channel for final ACK.

✓ Async callback channel
03. ROBUST IDEMPOTENCY

Rapid multi-clicks generate identical hash digests (author_id + cycle_period). n8n deduplicates active runs, returning the existing job ID rather than double-emailing authors.

✓ 15m Hash Collision Guard
